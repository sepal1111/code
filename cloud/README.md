# 找到寶藏吧！邏輯冒險 (Find the Treasure! Logic Adventure)

這是一個專為教育設計的網頁程式邏輯遊戲，旨在透過趣味的航海冒險，培養學生的運算思維（Computational Thinking）。玩家需要透過組合指令卡片，引導船隻在多變的海域中避開障礙、善用傳送門，最終精準抵達寶藏位置。

## 🎮 遊戲特色

- **七大挑戰關卡**：精心設計的冒險模式，從基礎移動到「時空金鑰」等複雜機制，難度循序漸進。
- **全方位功能模組**：
  - **冒險模式**：挑戰內建關卡，解鎖「傳奇航海家」成就。
  - **地圖編輯器**：直觀的視覺化編輯工具，支援自訂障礙、傳送門與起始點。
  - **自訂挑戰**：匯入編輯器產生的地圖代碼，與朋友分享或挑戰創意地圖。
  - **教學指南**：內建詳細的圖文操作說明。
- **豐富的程式邏輯元件**：
  - **指令卡片**：前進、後退、左轉、右轉、射擊（移除漂流木）。
  - **重複卡片**：x2、x3 包裹區塊設計，支援多層巢狀迴圈，學習迴圈概念。
  - **資源限制**：特定關卡限制指令數量，優化程式效率。
- **動態地圖機制**：
  - **障礙物 (礁石)**：需繞道而行的固定阻礙。
  - **傳送門 (渦流)**：空間跳躍的捷徑。
  - **金鑰系統**：需先取得鑰匙才能打開特定的寶藏箱。
- **📋 進度代碼系統**（新功能）：
  - 過關後自動記錄該關使用的積木序列。
  - 可將完整闖關進度（解鎖關卡 + 每關積木）壓縮為一段文字代碼，方便複製、下載或分享。
  - 匯入代碼後立即還原進度，並**完全覆蓋**瀏覽器現有紀錄，無縫跨裝置延續學習。
- **🏆 過關紀錄唯讀模式**（新功能）：
  - 進入已過關的關卡時，程式序列自動載入過關積木並**鎖定編輯**，以金色橫幅提示。
  - 仍可執行再次觀察路徑；點擊「清除全部」即可解鎖重新設計。
  - 匯入進度代碼後同樣支援此唯讀顯示。
- **👨‍🏫 教師評分管理**（新功能）：
  - 專屬的教師儀表板，支援輸入密碼進入。
  - 密碼格式為：code + 月日（各兩位數），例：code0518
  - 批量匯入學生的進度代碼，自動解析為包含班級、座號、通關數與各關積木數的總表。
  - 點擊「查看」自動跳轉至該學生的遊戲紀錄，還原通關路徑。
  - 支援一鍵匯出全班成績為 CSV 檔案。
- **現代化遊戲體驗**：
  - **自動擷取**：過關自動下載成果圖，方便學習記錄。
  - **影音沈浸**：豐富的背景音樂（BGM）與精確的音效反饋。
  - **響應式設計**：支援桌面與平板裝置。

## 🕹️ 如何遊玩

1. **選擇船隻**：在首頁選擇喜愛的頭像，這將作為您的執行角色。
2. **冒險/自訂**：選擇進入「闖關冒險」或「自訂挑戰」。
3. **編寫程式**：
   - 點擊藍色/紫色卡片添加動作。
   - 點擊橘色重複卡片，並透過「+」/「-」調整包裹範圍，將後續指令納入迴圈。
4. **執行與驗證**：
   - 點擊「🚀 開始航行」看著船隻依序執行。
   - **獲勝條件**：船隻必須在所有指令執行完畢時，**剛好停在寶藏（💰）位置**。
   - 若有金鑰要求，需先經過金鑰格。
5. **儲存與分享進度**：
   - 在左上角輸入「班級/座號」。
   - 點擊頂部「📋 進度代碼」按鈕，匯出當前進度代碼儲存或傳給同學/老師。
   - 收到別人的代碼時，在同一視窗切換至「匯入」頁籤貼上即可還原紀錄。

## 🛠️ 技術堆疊

- **核心**：HTML5, JavaScript (Vanilla ES6+)。
- **樣式**：Tailwind CSS (CDN 版本)。
- **工具套件**：
  - `dom-to-image`: 用於實現遊戲畫面擷取功能。
  - `Google Fonts`: 提供 Noto Sans TC 質感字體。
- **狀態管理**：使用 `localStorage` 持久化解鎖進度、每關積木紀錄、音量設定、自訂地圖及教師評分資料。
- **進度代碼格式**：Base64-URL 編碼的 JSON，包含版本號、解鎖關卡索引、全通旗標、班級座號、各關積木序列（精簡 ASCII 格式）。

## ☁️ 雲端版專屬：Google Sheets 串接指南

本版本為**雲端整合版**，支援將學生的闖關進度與創作的自訂地圖儲存到 Google Sheets。

### 1. 試算表建立步驟
在您的 Google 雲端硬碟中建立一個新的 **Google 試算表**，並新增以下兩個工作表（Sheets）：

#### 工作表 A：`Students` (儲存學生進度紀錄)
請在第一行建立以下四個欄位名稱（大小寫需完全一致）：
* `class_seat` (主鍵：班級_座號，例如 `301_05`)
* `pin` (6 位數字安全 PIN 碼)
* `progressCode` (進度代碼字串)
* `updatedAt` (最後更新時間)

#### 工作表 B：`CustomMaps` (儲存學生自訂地圖)
請在第一行建立以下七個欄位名稱：
* `class_seat` (上傳者帳號，例如 `301_05`)
* `pin` (創作密碼鎖，6 位數字)
* `mapId` (地圖唯一識別碼，時間戳記)
* `mapName` (地圖名稱)
* `mapDesc` (地圖介紹)
* `mapCode` (地圖 Base64 代碼)
* `date` (儲存時間)

---

### 2. 部署 Apps Script 網頁應用程式
1. 在該試算表中，點擊選單的 **「擴充功能」 -> 「Apps Script」**。
2. 將本專案專屬的後端程式碼（可在 [google_sheets_final_implementation_plan.md](file:///C:/Users/kyps07/.gemini/antigravity/brain/84dad0a9-9144-4260-9e35-6be239984190/artifacts/google_sheets_final_implementation_plan.md) 中找到）複製貼上至 `程式碼.gs` 中。
3. 點擊頂部的 **「儲存」** 圖示。
4. 點擊右上角的 **「部署」 -> 「新增部署」**：
   - 類型選擇：**「網頁應用程式」** (Web App)。
   - 說明：`找到寶藏雲端API`。
   - 執行身份：**「我」** (您的 Google 帳號)。
   - 誰有權限存取：**「所有人」** (Anyone)。
5. 點擊 **「部署」**，並授權您的 Google 帳號權限。
6. 複製產生的 **「網頁應用程式 URL」** (URL 結尾通常為 `/exec`)。

---

### 3. 設定前端網頁
1. 在 `cloud` 資料夾中打開 [config.js](file:///d:/桌面/code/cloud/config.js)。
2. 將剛才複製的網頁應用程式 URL 貼入 `GOOGLE_SHEETS_API_URL` 欄位中：
   ```javascript
   const CONFIG = {
       GOOGLE_SHEETS_API_URL: "https://script.google.com/macros/s/AKfycb...你的ID.../exec"
   };
   ```
3. 儲存 [config.js](file:///d:/桌面/code/cloud/config.js) 檔案，即刻完成全站的雲端串接！

### 💡 雲端功能使用說明：
* **學生讀取/首次存檔**：學生在遊戲頁面輸入班級、座號與自訂的 **6 位數 PIN 碼**，點選 **「☁️ 讀取進度」**。若首次登入會自動以該 PIN 碼在雲端開戶。後續過關時，系統會**背景自動靜默上傳**最新進度，防止資料丟失。
* **雲端地圖庫**：在地圖編輯器中輸入班級、座號與 6 位 PIN 碼，即可隨時將關卡「☁️ 存至雲端」或從雲端「☁️ 下載地圖」，建立個人專屬的創作空間。
* **教師自動評分**：教師輸入今日密碼進入教師控制台時，系統會**自動從 Google Sheets 拉取所有學生的實時進度**，無需手動複製代碼！
