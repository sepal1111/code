# 找到寶藏吧！邏輯遊戲 (Find the Treasure! Logic Game)

這是一個專為教育設計的網頁程式邏輯遊戲。玩家需要透過組合指令卡片，引導船隻避開礁石、穿過傳送門，最終精準地抵達寶藏的位置。

## 🎮 遊戲特色

- **六大挑戰關卡**：從基本的自由航行到複雜的綜合闖關，難度循序漸進。
- **視覺化程式設計**：使用直觀的指令卡片（前進、後退、旋轉、重複）來規劃路徑。
- **資源管理機制**：部分關卡限制了特定指令的使用次數，考驗玩家的邏輯優化能力。
- **豐富的地圖元素**：包含障礙物（礁石）、傳送門（渦流）等互動元素。
- **成就系統**：完成所有關卡可獲得「傳奇航海家」勳章。
- **影音體驗**：內建隨機背景音樂與互動音效，並提供音量調節功能。
- **進度擷取**：過關後可一鍵擷取遊戲畫面，方便學生記錄或分享學習成果。

## 🕹️ 如何遊玩

1. **選擇船隻**：在首頁選擇您喜愛的船隻外觀後點擊「啟航」。
2. **規劃路徑**：
   - 點擊藍色的**指令卡片**來添加動作（前進、後退、旋轉）。
   - 點擊橘色的**重複卡片**（x2, x3）來倍增最後一個指令的效果。
3. **執行程式**：點擊「🚀 開始航行」，船隻將依照順序執行您的指令。
4. **過關條件**：船隻必須在所有指令執行完畢後，**剛好停在寶藏（💰）的位置**才算過關。
5. **進度管理**：
   - 點擊「復原」移除最後一個指令。
   - 點擊「清除全部」重設程式序列。
   - 過關後可點擊「📷 擷取過關畫面」下載圖片。

## 🛠️ 技術開發

- **核心技術**：HTML5, Vanilla JavaScript (純 JavaScript)。
- **樣式框架**：Tailwind CSS。
- **截圖套件**：`dom-to-image`。
- **音訊處理**：Web Audio API 與原生 Audio 標籤。
- **進度儲存**：使用瀏覽器的 `localStorage` 儲存解鎖進度。

## 📁 檔案結構

- `index.html`: 遊戲主程式與樣式。
- `music/`: 背景音樂資料夾（需放入 `bgm1.mp3`, `bgm2.mp3` 等檔案）。
