# 找到寶藏吧！邏輯冒險 (Find the Treasure! Logic Adventure)

這是一個專為教育設計的網頁程式邏輯遊戲，旨在透過趣味的航海冒險，培養學生的運算思維（Computational Thinking）。玩家需要透過組合指令卡片，引導船隻在多變的海域中避開障礙、善用傳送門，最終精準抵達寶藏位置。

## 🎮 遊戲特色

- **七大挑戰關卡**：精心設計的冒險模式，從基礎移動到「時空金鑰」等複雜機制，難度循序漸進。
- **全方位功能模組**：
  - **冒險模式**：挑戰內建關卡，解鎖「傳奇航海家」成就。
  - **地圖編輯器**：直觀的視覺化編輯工具，支援自訂障礙、傳送門與起始點。
  - **自訂挑戰**：匯入編輯器產生的地圖代碼，與朋友分享或挑戰創意地圖。
  - **教學指南**：內建詳細的圖文操作說明。
- **豐富的程式邏輯元件**：
  - **指令卡片**：前進、後退、左轉、右轉、射擊（移除漂流木）。
  - **重複卡片**：x2、x3 倍增效果，學習迴圈概念。
  - **資源限制**：特定關卡限制指令數量，優化程式效率。
- **動態地圖機制**：
  - **障礙物 (礁石)**：需繞道而行的固定阻礙。
  - **傳送門 (渦流)**：空間跳躍的捷徑。
  - **金鑰系統**：需先取得鑰匙才能打開特定的寶藏箱。
- **現代化遊戲體驗**：
  - **自動擷取**：過關自動下載成果圖，方便學習記錄。
  - **影音沈浸**：豐富的背景音樂（BGM）與精確的音效反饋。
  - **響應式設計**：支援桌面與平板裝置。

## 🕹️ 如何遊玩

1. **選擇船隻**：在首頁選擇喜愛的頭像，這將作為您的執行角色。
2. **冒險/自訂**：選擇進入「闖關冒險」或「自訂挑戰」。
3. **編寫程式**：
   - 點擊藍色/紫色卡片添加動作。
   - 點擊橘色重複卡片來循環上一個動作。
4. **執行與驗證**：
   - 點擊「🚀 開始航行」看著船隻依序執行。
   - **獲勝條件**：船隻必須在所有指令執行完畢時，**剛好停在寶藏（💰）位置**。
   - 若有金鑰要求，需先經過金鑰格。

## 🛠️ 技術堆疊

- **核心**：HTML5, JavaScript (Vanilla ES6+)。
- **樣式**：Tailwind CSS (CDN 版本)。
- **工具套件**：
  - `dom-to-image`: 用於實現遊戲畫面擷取功能。
  - `Google Fonts`: 提供 Noto Sans TC 質感字體。
- **狀態管理**：使用 `localStorage` 持久化解鎖進度、音量設定與自訂地圖。

## 📁 檔案結構

- `index.html`: 遊戲入口與角色選擇頁面。
- `adventure.html`: 闖關冒險模式（包含 7 個主要關卡）。
- `editor.html`: 地圖編輯器工具。
- `custom.html`: 自訂地圖挑戰頁面。
- `tutorial.html`: 遊戲說明與指南。
- `music/`: 音效與背景音樂資源。
